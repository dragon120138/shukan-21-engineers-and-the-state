# 书刊21 工程师与国家产业与治理的一个命题

> 学术·工业史

## 关于本书

工程师与国家的关系是被宏大叙事遮蔽的历史：现代国家的能力很大程度是工程能力的国家化——从铁路勘到电网调度，从两弹一星到登月。横跨三世纪多国：凡勃伦的工程师乌托邦、苏联计划工程师、美国技术官僚争论、东亚发展型国家的工程军团。每章讨论工程能力如何进入国家机器，又如何被政治逻辑驯化或释放。
